## 📌 Overview

This repository contains the source code for my personal portfolio. It serves as a central hub for my resume, technical projects, and engineering blog. 

The site is built as a single-page static site, focusing on performance, accessibility, and a clean user experience across both light and dark modes.

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (No heavy frameworks or build steps)
- **Styling:** CSS Variables (Custom properties) for theming, Flexbox/Grid for layout
- **Icons & Fonts:** Font Awesome, Google Fonts (Inter + JetBrains Mono)
- **Contact Form:** Formspree (AJAX integration)
- **Hosting:** GitHub Pages

## 📂 Project Structure

```text
/
├── index.html      # Main HTML structure and content
├── styles.css      # Styling, CSS variables (dark/light mode), and responsive design
├── script.js       # Theme toggle, mobile navigation, smooth scrolling, and form handling
└── README.md
```

## 🚀 Deployment

Deployment is automated via GitHub Pages. Any push to the `main` branch immediately updates the live site. No CI/CD pipeline or manual build step is required.
